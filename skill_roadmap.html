PHASE 0 Excel First — Every BI Tool Starts Here ⏱ Day 1–5 · The universal foundation

💡 WHY START WITH EXCEL?

Excel shares the same mental model as Power BI and Tableau — rows, columns, filters, pivots. 90% of business analysts use Excel daily. If you can build a pivot table in Excel, learning Power BI becomes 3x faster. Don't skip this even if it feels basic.

📊 Excel Essentials

0%
  • SUM, AVERAGE, COUNT, MIN, MAX — core formulas
  • IF, COUNTIF, SUMIF, AVERAGEIF — conditional formulas 🔥 HOT
  • VLOOKUP / XLOOKUP — the most-used Excel skill in business 🔥 HOT
  • INDEX / MATCH — more powerful than VLOOKUP
  • Absolute vs relative cell references ($A$1 vs A1) 📌 FREQ
  • Text functions: TRIM, LEFT, RIGHT, MID, CONCATENATE
  • Conditional formatting — visual data analysis

🔄 Pivot Tables (Gateway to BI)

0%
  • Create a pivot table from a flat data table 🔥 HOT
  • Rows, Columns, Values, Filters — the four pivot areas
  • Group by date (year/month/quarter) in pivot 📌 FREQ
  • Add slicers for interactive filtering
  • Build a chart from a pivot table (bar, line, combo)
  • Create a simple 1-page Excel dashboard with charts + slicers 🏆 MILESTONE

🚀 Power BI First Look

0%
  • Download Power BI Desktop (free)
  • Understand the 3 views: Report / Data / Model
  • Load a CSV file and build your first visual (bar chart)
  • Add a slicer and see cross-filtering in action
  • Write your first DAX measure: Total Sales = SUM(Sales[Amount])
